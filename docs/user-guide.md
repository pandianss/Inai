# How to Use Bharat Messenger - Quick Guide

## 🚀 Getting Started

### 1. **Onboarding** (First Time Only)

When you first open the app:

1. **Language Selection**
   - App automatically suggests language based on your location
   - See "Suggested for [Your City], [Your Region]"
   - Click on your preferred language
   - Click "Continue"

2. **Enter Your Name**
   - Type your name in the input field
   - OR click "Speak" button to use voice input
   - Click "Continue"

3. **Welcome Screen**
   - Review app features (E2E Encryption, AI Translation, UPI Payments)
   - Click "Get Started"

## 💬 Using the Chat Function

### Accessing Chat

The app has **3 main sections** accessible via bottom navigation:

```
┌─────────────────────────────────────┐
│  [Chat]  [समूह]  [बाज़ार]  [Profile] │
└─────────────────────────────────────┘
```

- **Chat** (leftmost icon) - Personal 1-on-1 messaging
- **समूह** (Groups) - Community group chats
- **बाज़ार** (Commerce) - ONDC marketplace
- **Profile** - User settings

### Sending Messages

**In Chat View:**

1. **Type a Message**
   - Click the input field at the bottom
   - Type your message in Hindi or English
   - Placeholder says: "संदेश लिखें..." (Write message...)

2. **Send Options**
   - **Press Enter** on keyboard to send
   - **Click Send Button** (arrow icon on right)
   - Button is disabled if message is empty

3. **Additional Options**
   - **📎 Attach** - Click paperclip icon (left) to attach files
   - **🎤 Voice** - Click microphone icon to send voice message

### Message Features

**Auto-Response Demo:**
- When you send a message, the app simulates a response
- You'll see a typing indicator (three dots)
- After 1.5 seconds, you get a random Hindi response

**Message Display:**
- **Your messages** - Orange gradient bubbles on the right
- **Received messages** - Light sandalwood bubbles on the left
- **Timestamps** - Small text showing time in HH:MM format

## 👥 Using Groups

### Viewing Groups

1. Click **"समूह"** (Groups) tab in bottom navigation
2. See list of your groups:
   - **टीम अल्फा** (Official group with time controls)
   - **परिवार समूह** (Family group, no restrictions)

### Creating a New Group

1. Click **"+ Create Group"** button
2. Follow 4-step wizard:

   **Step 1: Select Type**
   - Official (70% approval needed)
   - Social (60% approval)
   - Interest (60% approval)
   - Temporary (50% approval)

   **Step 2: Details**
   - Enter group name
   - Enter purpose
   - Set expected member count

   **Step 3: Rules**
   - Toggle time controls ON/OFF
   - Select active days (Mon-Sun)
   - Set time range (e.g., 9 AM - 6 PM)
   - Add group guidelines

   **Step 4: Review**
   - Review all settings
   - Click "Submit for Voting"
   - Wait for community approval (48 hours)

### Chatting in Groups

1. Click on a group from the list
2. **If time controls are active:**
   - See banner: "संदेश अक्षम हैं" (Messages disabled)
   - Countdown shows when group reopens
   - Type messages to save as drafts
   - Use emergency keywords to bypass

3. **If messaging is allowed:**
   - Chat normally like 1-on-1
   - See sender names above messages
   - All features work

## 🛒 Using Commerce (बाज़ार)

1. Click **"बाज़ार"** tab
2. Browse categories: Grocery, Food, Transport, Medicine
3. Click **"+"** button to add items to cart
4. Cart summary appears at bottom
5. Click **"Pay Now (UPI)"** to complete purchase

## ⚡ Quick Tips

### Keyboard Shortcuts
- **Enter** - Send message
- **Shift + Enter** - New line in message

### Message States
- **Typing...** - Other person is typing
- **Disabled Input** - Group time controls active
- **Draft Saved** - Message saved for later

### Emergency Messages (Groups)
Use these keywords to bypass time controls:
- English: `emergency`, `urgent`, `critical`
- Hindi: `आपातकाल`, `जरूरी`

## 🎯 Main Use Cases

### Personal Chat
1. Open app → Already in Chat view
2. Type message → Press Enter or click Send
3. See response after 1.5 seconds

### Official Group (Work)
1. Click "समूह" tab
2. Click "टीम अल्फा"
3. If during work hours (9 AM - 6 PM, Mon-Fri):
   - Chat normally
4. If outside hours:
   - See "Messages disabled" banner
   - Type to save draft
   - Use "emergency" for urgent messages

### Shopping
1. Click "बाज़ार" tab
2. Browse merchants
3. Add items with "+" button
4. Click "Pay Now (UPI)"

## 🐛 Troubleshooting

**Issue**: Can't see messages
- **Solution**: Scroll down in messages area

**Issue**: Send button disabled
- **Solution**: Type something in the input field first

**Issue**: Group messages disabled
- **Solution**: Check time controls, wait for active hours, or use emergency keywords

**Issue**: Dotted lines near chat bubbles
- **Solution**: Fixed! Refresh the page (Ctrl+R)
